# Extension Icons

This directory needs icon files for the Chrome extension:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

You can create these icons from any YouTube-related icon or logo.

## Quick way to create icons:

1. Find a suitable icon (e.g., a play button or YouTube-style icon)
2. Use an online tool like https://realfavicongenerator.net/
3. Generate icons in the required sizes
4. Save them in this directory

Or you can use a simple red circle as a placeholder:
- Create a red circle in any image editor
- Export in the required sizes
